# Apple review recording — build 3

Record on the physical iPhone, not the simulator or design prototype. Start only after the installed app version is confirmed as 1.0.0 (3).

1. Enable Do Not Disturb to hide private notification banners. Start iPhone Screen Recording from Control Centre, return to the Home Screen, then launch Furnio.
2. Show signup with a disposable account and the real verification flow. Keep passwords and one-time codes out of the final shared video. Show the trial allowance and restricted services if currently enabled.
3. Sign out, then sign in. Use a funded test account to demonstrate paid service access through its existing shared credits; do not purchase or claim there are native purchases.
4. Create a property. Show address suggestions, select an address and show its map. Select a photo you own or are licensed to use.
5. Select Virtual Staging, room type, furniture style and mood. Show the confirmation, AI disclosure and credit cost. Submit only with the owner's approval; this consumes a real credit allowance and provider usage.
6. Wait for the result. Show before/after and save the completed image. Avoid accidentally sending it to another person from the Share sheet.
7. Separately demonstrate Item Removal/Custom Staging against an existing completed job, or an owner-approved new job: multiple selected regions must produce one final deliverable. Check for freezes while navigating and backgrounding/foregrounding.
8. Use only the disposable account for Account → privacy/deletion. Show recent-authentication, confirmation and the request receipt/completion window. Do not delete the funded reviewer account. Do not describe an accepted asynchronous deletion request as an already-deleted account.
9. Stop recording. Review it for private notifications, unrelated customer data, passwords and verification codes. Supply the approved recording file to Codex for attachment to Apple's reply.

The response must include the actual device, OS, app/build number and recording date. It must be posted to both the App Review conversation and App Review Information Notes. Build upload is not review submission, and neither is public approval.
